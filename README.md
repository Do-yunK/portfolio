# Welcome to my portfolio !

## Adding case study visuals

Add text and images inside the relevant article in `casestudy1.html`, `casestudy2.html`, or `casestudy3.html`. Use the existing `case-study-feature-image` class for full-width, uncropped visuals:

```html
<p>Describe the research finding or design decision here.</p>
<img src="images/your-image.png" class="case-study-feature-image" alt="Describe the visual">
```

Replace the example path and alt text with your own image and description. Existing wireframe images can also be replaced with project-specific visuals.
